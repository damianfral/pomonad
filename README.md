# pomonad

A pomodoro timer in the terminal,
built with [brick](https://github.com/jtdaugherty/brick).


## Running

```sh
$ nix run github:damianfral/pomonad
```

## Controls

| Key      | Action      |
| -------- | ----------- |
| `Space`  | start/pause |
| `r`      | reset       |
| `q`/`Esc`| quit        |
